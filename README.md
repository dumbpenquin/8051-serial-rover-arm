# 🤖 8051-serial-rover-arm

> A UART-controlled robotic rover with a 4-DOF servo arm and payload deployment system, built entirely on the **8051 microcontroller** using Embedded C — no RTOS, no libraries, just bare-metal hardware control.

## Overview

SENTRY-V is a two-part embedded system:

- **Rover** — a DC motor-driven vehicle steered via single-character serial commands over UART
- **Robotic Arm** — a 4-servo arm (base, shoulder, elbow, gripper) with software PWM generated by a Timer0 ISR
- **Payload Deployment** — an abortable 10-second countdown sequence with buzzer alerts and LCD status
- **Status Display** — a 16×2 I²C LCD showing real-time system state for every command

All servo PWM, motor control, LCD communication, and UART handling run concurrently on a single 8051 with no operating system.

## Hardware

| Component | Purpose |
|-----------|---------|
| 8051 (AT89S52 or compatible) | Main MCU |
| DC Motors × 2 (via P2 H-bridge) | Rover drive |
| Servo Motors × 4 (P0.0–P0.3) | Robotic arm joints |
| 16×2 LCD with I²C backpack (PCF8574) | Status display |
| Active Buzzer (P2.6) | Audio feedback |
| UART Serial (9600 baud) | Command input |
| Crystal 11.0592 MHz | Baud rate accuracy |

## Serial Command Reference

Connect at **9600 8N1**. Send single ASCII characters. CR/LF are ignored.

### Drive

| Key | Action |
|-----|--------|
| `F` | Forward |
| `B` | Backward |
| `L` | Turn Left |
| `R` | Turn Right |
| `S` | Stop |

### Arm

| Key | Joint | Action |
|-----|-------|--------|
| `1` | Base | Rotate left |
| `2` | Base | Center |
| `3` | Base | Rotate right |
| `4` | Shoulder | Down |
| `5` | Shoulder | Center |
| `6` | Shoulder | Up |
| `7` | Elbow | Fold |
| `8` | Elbow | Center |
| `9` | Elbow | Extend |
| `G` | Gripper | Open |
| `H` | Gripper | Close |
| `0` | All joints | Full center + beep |

### System

| Key | Action |
|-----|--------|
| `D` | Start 10-second payload deployment countdown |
| `A` | Abort countdown (only valid during countdown) |

## How It Works

### Servo PWM — Timer0 ISR

All four servos are driven by a single **Timer0 ISR firing every 100 µs**:

```
1 tick   = 100 µs
10 ticks = 1000 µs → 0°
15 ticks = 1500 µs → 90° (neutral)
20 ticks = 2000 µs → 180°
200 ticks = 20 ms  → 50 Hz period
```

On tick 1, all servo pins go HIGH. Each pin goes LOW when `servo_count` reaches its `servo_ticks` value. This gives independent pulse-width control for all four servos without dedicated PWM hardware.

### Countdown Sequence

Sending `D` triggers:
1. Motors stop, state locked to `COUNTDOWN` — all other commands ignored
2. LCD: `PAYLOAD ARMED / STAND CLEAR` for 1.5 s
3. Counts 10 → 1 with `DEPLOY IN: XX SEC` on LCD
4. Short beep each second above 3; double fast beep for final 3
5. `A` aborts at any point → `ABORTED / SAFE MODE`
6. At 0 → `DEPLOYED / MISSION DONE`, long beep, returns to idle

### I²C LCD

Software bit-bang I²C on P2.4/P2.5 drives a PCF8574 backpack in 4-bit mode. Each byte is split into upper and lower nibbles, each sent with an EN pulse.

## Building & Flashing

1. Open `src/main.c` in **Keil µVision**
2. Set target to AT89S52, crystal to **11.0592 MHz**
3. Build → flash via USBasp or any 8051 ISP programmer

> ⚠️ 11.0592 MHz is required for accurate 9600 baud. A standard 12 MHz crystal will cause UART errors.
